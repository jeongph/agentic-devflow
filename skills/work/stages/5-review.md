# 5. review — 리뷰 팬아웃

## 입력

- `base`, 현재 브랜치
- 변경 파일 목록: `git diff --name-only origin/<base>...HEAD`
- `이슈 요약`, `확정된 범위` (있으면)
- 설정 `review_model`, `reviewers`
- 관점 인자 (`review` 스킬에서 온 경우)

## 절차

`references/review-agents.md`의 세 절차를 순서대로 따른다. 이 파일은 절차를 복제하지 않는다.

1. **선택** — "선택표"로 돌릴 에이전트를 정한다. 관점 인자를 받았으면 "관점 인자 매핑"을 대신 쓴다. 해소되지 않는 도메인 리뷰어는 경고 후 제외한다.
2. **호출** — "호출 규약"대로 Agent 도구를 **한 메시지에서 병렬** 호출한다. 모든 호출에 `model: <review_model>`을 명시한다. 빠뜨리면 inherit 에이전트가 세션 모델로 돈다.
3. **집계** — "집계" 형식으로 보고서를 만든다. 끝에 돌린 에이전트와 모델을 적는다.

변경 파일이 0개면 중단하고 알린다: "base 대비 변경이 없습니다."

## 게이트

없다. 보고만 한다. 반영 여부는 6-apply에서 결정한다.

## 출력

- `리뷰 결과` (집계 형식)
- 돌린 에이전트 목록과 모델, 제외된 리뷰어와 사유
